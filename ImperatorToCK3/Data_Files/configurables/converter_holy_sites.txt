# This file looks very much like holy site definitions in the CK3 1.20+ common/religion/holy_site_types folder.
# The only difference is that instead of "county =", "county_choices =" can be used to allow multiple alternative counties.
# This is useful for CK3 mod compatibility.
#
# CK3 1.20+ split the old "character_modifier" block in two:
#   - "faith_character_modifier" applies to all characters of the faith, but only for eminent holy sites.
#   - "county_holder_character_modifier" applies to the county holder, for regular and eminent holy sites.
# Converter sites define their effects in both blocks, so every site keeps a local bonus even when it is
# not one of the faith's (at most 3) eminent holy sites.
# The legacy "character_modifier" block and "flag = x" key are no longer supported;
# flags are now defined with "parameters = { x }".
